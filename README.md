# Marketing Capstone Project

## Project Overview

An end-to-end marketing data analytics project focused on exploring marketing performance, identifying key trends, and generating actionable business insights using Python, Excel, and Tableau.

## Tools & Technologies

Python (Jupyter Notebook): Data cleaning and exploratory data analysis (EDA).

Excel: Data sources and supporting reference information.

Tableau: Interactive dashboards and data visualisation.

## Project Workflow

Data understanding and preparation

Data cleaning and exploratory analysis using Python

Identification of trends, patterns, and relationships

Interactive dashboard development using Tableau

Technical reporting and business insights

## Repository Contents

MarketingCapstone.ipynb – Python analysis

data.xlsx, Country-Code.xlsx, variable description.xlsx – Supporting datasets

MarketingCapstoneProject.twbx – Tableau dashboard

Marketing_Capstone_Technical Document.pdf – Project documentation

## Outcome

Demonstrates practical skills in data analysis, visualisation, and translating analytical findings into business insights to support data-driven decision-making.
